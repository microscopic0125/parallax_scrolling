# Techfest 2026 — Enter the Unknown

A responsive, single-page landing page concept for Techfest IIT Bombay 2026, featuring space-inspired artwork, layered parallax, and scroll-triggered animations.

## Run locally

Open `index.html` in a modern web browser. No build step or package installation is required.

The page uses Google Fonts when an internet connection is available and falls back to system sans-serif fonts otherwise.

## Features

- Responsive desktop and mobile layouts
- Scroll-driven parallax, scaling, and fade effects
- Reduced-motion preference support
- Mobile navigation and an email signup form preview

The signup form is a frontend preview and is not connected to a mailing list.
